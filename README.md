# HRMS RAG Chatbot

A document-grounded (RAG) customer-support chatbot for the **fabrIQ HRMS**, built with
**Streamlit · LangChain · ChromaDB · Google Gemini**. It answers questions using
**only** your uploaded documents and cites the sources it used.

## How it works

```
Question → retrieve top-k chunks from ChromaDB → stuff into prompt
        → Gemini generates a grounded answer → answer + sources
```

- `app.py` — Streamlit UI (chat, file upload, source display)
- `rag_chain.py` — the RAG pipeline (retriever + Gemini + conversation memory)
- `ingest.py` — loads PDF/TXT docs, chunks, embeds, stores in ChromaDB
- `knowledge_base/` — source documents (e.g. `HRMS_Helpdoc.txt`)

## Setup

1. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

2. **Add your API key** — copy the example and paste your Gemini key
   ```bash
   cp .env.example .env
   ```
   Get a key at https://aistudio.google.com/app/apikey and set `GOOGLE_API_KEY` in `.env`.

3. **Ingest your documents** (builds `chroma_db/`)
   ```bash
   python ingest.py
   ```

4. **Run the app**
   ```bash
   streamlit run app.py
   ```
   Open http://localhost:8501

## Configuration (`.env`)

| Variable | Default | Notes |
|---|---|---|
| `GOOGLE_API_KEY` | — | Required. Your Gemini API key. |
| `GEMINI_MODEL` | `gemini-flash-latest` | Chat model. Swap if a model is unavailable/exhausted on your key (e.g. `gemini-flash-lite-latest`, `gemini-2.5-flash`). |
| `GEMINI_EMBED_MODEL` | `models/gemini-embedding-001` | Embedding model. Must match between ingest and query. |

> **Free-tier note:** Gemini's free tier caps each model at ~20 requests/day and the
> embedding endpoint at ~5 requests/minute. The app auto-retries transient 429/500/503
> errors with backoff; for heavier use, enable billing on your Google AI Studio project.

## Notes

- `.env` and `chroma_db/` are gitignored — your key stays local and the vector store is
  regenerated by `ingest.py`.
- If you change the embedding model, delete `chroma_db/` and re-run `ingest.py`.
